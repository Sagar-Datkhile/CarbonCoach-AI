## 4. Important Architectural Decisions
* **Strict Anti-Fabrication Rule:** Zero mock numbers inserted into user database state.
* **Deterministic Calculations:** Energy reductions and financial savings are strictly computed mathematically via verified formulas in TypeScript rather than generated by LLMs.
* **Hydration Protection:** Root layout specifies `suppressHydrationWarning` to tolerate browser extension DOM mutations on root elements.
